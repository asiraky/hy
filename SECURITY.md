# Security policy

## Reporting a vulnerability

Do not disclose suspected vulnerabilities in a public issue. Use GitHub's
[private vulnerability reporting](https://github.com/asiraky/hy/security/advisories/new)
to send a report to the maintainer.

Include the affected version or commit, reproduction steps, impact, and any
suggested mitigation. You should receive an acknowledgement within seven days.

Only the latest revision of `main` is currently supported with security fixes.
